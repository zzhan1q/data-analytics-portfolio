# Выдачи Seattle Public Library, 2022–2024

[Открыть HTML-отчёт](report.html) · [Сводка CSV](summary.csv) · [Скриншот отчёта](preview.png)

Как менялось соотношение цифровых и физических выдач с января 2022 по декабрь 2024 года?

| Год | Цифровые | Физические | Всего | Доля цифровых |
|---|---:|---:|---:|---:|
| 2022 | 4 692 195 | 3 710 181 | 8 402 376 | 55,8437% |
| 2023 | 5 476 658 | 3 720 574 | 9 197 232 | 59,5468% |
| 2024 | 5 366 644 | 2 954 034 | 8 320 678 | 64,4977% |

- За 36 месяцев — **25 920 286 выдач**: 15 535 497 цифровых и 10 384 789 физических. Цифровых было больше в каждом из 36 месяцев.
- С 2022 по 2024 год цифровая доля выросла на **8,6540 п. п.** При этом в 2024 году цифровых выдач стало на 110 014 меньше, чем в 2023-м, а физических — на 766 540 меньше. Рост доли не означает роста числа выдач.
- Самый активный месяц — январь 2024 года (**849 428** выдач); самая высокая доля цифрового формата — в июле 2024 года (**80,8856%**).

## Метод и проверка

Источник: городской набор [Checkouts by Title](https://data.seattle.gov/Community-and-Culture/Checkouts-by-Title/tmmm-ytt6), **Public Domain**. Socrata возвращает только агрегаты: `SUM(checkouts)` по году, месяцу и `usageclass`. Скрипт проверяет наличие ровно одной группы на каждый из 36 месяцев и двух форматов, допустимость счётчиков и совпадение годовых сумм с отдельным запросом к API без разбиения по формату. Затем запускается `analysis.sql` в SQLite в памяти: SQL считает те же показатели, выявляет нарушения и сверяется с Python построчно. В выгрузке 72 группы и 3 контрольных итога, расхождений нет.

Годовая доля = сумма цифровых выдач / сумма всех выдач за год, а не среднее месячных долей. `summary.csv` содержит 36 строк `month` и 3 строки `year`; `digital_share_pct` — проценты с четырьмя знаками после точки. Исходные записи и персональные поля не загружаются и не сохраняются.

## Ограничения

Это количество выдач, не число уникальных читателей, названий или экземпляров. Это срез открытого набора, а не официальный полный оборот библиотеки: [годовой отчёт SPL](https://www.spl.org/Seattle-Public-Library/documents/about-us/impact/2024StatisticalFinancialSummaryOnePage.pdf) указывает 10,8 млн за 2024 год и отмечает сбой сервисов выдачи с мая по сентябрь 2024 года. По наблюдаемым долям нельзя установить причину изменений или измерить спрос отдельно от доступности сервиса. Источник может пересматривать исторические данные.

## Воспроизведение

Python 3.8+ (только стандартная библиотека). Для пересчёта нужен интернет; готовый HTML открывается с диска без сети, а тесты работают на локальных примерах.

```sh
python analyze.py
python -B -m unittest discover -s tests -v
```
