# Устойчивость доли переводов в ВВП

В Таджикистане доля переводов в ВВП колебалась между 26,88% и 49,90% за 2019–2023 годы. Размах по неокруглённым данным — 23,01 п. п., самый большой среди 52 экономик, прошедших фильтр покрытия и средней доли.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

`GROUP BY` собирает пять годовых долей в один ряд. SQL проверяет полноту и среднюю долю; формула Excel вычитает минимум из максимума. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

Размах взят за 2019–2023 годы только для экономик с пятью наблюдениями. Для сравнения оставлены экономики со средней долей не менее 5% ВВП; размах не показывает направление изменений.

**Источник.** Всемирный банк, World Development Indicators: [`BX.TRF.PWKR.DT.GD.ZS`](https://data.worldbank.org/indicator/BX.TRF.PWKR.DT.GD.ZS). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
