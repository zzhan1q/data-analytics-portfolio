# Когда интернетом стала пользоваться половина населения

В 95 экономиках есть наблюдаемый переход от значения ниже 50% к значению не ниже 50%. В Аргентине последнее наблюдение ниже порога относится к 2010 году, первое после него — к 2011-му. В таблице видны оба года и расстояние между ними.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

`LAG` находит предыдущее наблюдение; `ROW_NUMBER` оставляет первый переход. Формула Excel вычитает годы, а не проценты. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

Учитывается первое наблюдаемое достижение порога после значения ниже 50%; уже превышавшие порог при первом наблюдении сюда не входят. Между двумя измерениями точную дату перехода не определить.

**Источник.** Всемирный банк, World Development Indicators: [`IT.NET.USER.ZS`](https://data.worldbank.org/indicator/IT.NET.USER.ZS). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
