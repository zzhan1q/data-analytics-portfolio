# Как изменился ранг экономик по доле населения 65+

Северные Марианские острова поднялись со 178-го места в 2010 году на 103-е в 2023-м. В обоих рейтингах 217 одних и тех же экономик. Столбец «Подъём» показывает изменение места, а не прирост доли 65+.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

`RANK()` присваивает места отдельно за каждый год после объединения двух срезов. Excel показывает разность мест. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

Ранги рассчитаны на одном составе экономик. Первое место у наибольшей доли населения 65+; при равенстве долей ранг одинаковый.

**Источник.** Всемирный банк, World Development Indicators: [`SP.POP.65UP.TO.ZS`](https://data.worldbank.org/indicator/SP.POP.65UP.TO.ZS). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
