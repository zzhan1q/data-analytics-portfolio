# Землетрясения M ≥ 5 в каталоге USGS, 2023–2024

[Офлайн-отчёт](report.html) · [Превью](preview.png) · [Агрегированный CSV](summary.csv)

В выгрузке по всему миру — **3 287** землетрясений: **1 780** в 2023 году и **1 507** в 2024-м. Больше всего событий за один месяц — **281** в декабре 2023 года.[5]

| Группировка | Число событий |
|---|---:|
| Магнитуда: 5 ≤ M < 6 / 6 ≤ M < 7 / 7 ≤ M < 8 / M ≥ 8 | 3 041 / 217 / 29 / 0 |
| Глубина: < 70 км / 70–<300 км / ≥ 300 км / неизвестна | 2 668 / 490 / 129 / 0 |

Фильтры USGS: `eventtype=earthquake`, `minmagnitude=5`, без географических ограничений; время события в UTC от **2023-01-01 00:00** включительно до **2025-01-01 00:00** исключительно.[5] Скрипт дополнительно проверяет границы и сверяет размер выгрузки с `/count`. Пустые или некорректные глубины идут в отдельную группу; отрицательные глубины включаются в `< 70 км`. ID проверяются, совпадающие по времени, магнитуде и глубине повторы считаются один раз, конфликтующие останавливают расчёт. В этой выгрузке повторов и строк за пределами фильтров не было.[5]

В CSV только агрегаты: 24 месяца, 4 группы магнитуд и 4 группы глубин. Каталог обновляется; числа описывают выгрузку, а не риск или прогноз. Магнитуды разных типов не приводятся к общей шкале.

Для пересчёта нужен интернет; готовый HTML и тесты работают без сети.

```sh
python3 analyze.py
python3 -m unittest discover -s tests -v
```
